# Demo media

Add short authorized clips with these filenames: `normal-beach.mp4`, `distress-shout.mp4`, `swimmer-distress.mp4`, `pulled-by-surf.mp4`, `motionless-person.mp4`, and `dangerous-surf.mp4`.

Clips should be under 60 seconds. Gemma 4 supports at most 30 seconds of native audio; 10–25 second clips are ideal for demo latency.
